# Напоминалка пить воду (reminder.py)

Простой скрипт для Windows 10: напоминает пить воду 6 раз в день, пишет лог и показывает уведомления средствами Windows. Рассчитано на начинающего (уровень 5 класса).

## Что делает скрипт

- Показывает напоминания в 08:00, 10:30, 13:00, 15:30, 18:00, 20:30.
- Выводит понятное сообщение в консоль: «Пора пить воду! Выпей 250 мл.»
- Показывает всплывающее уведомление Windows (без сторонних библиотек).
- Пишет события в файл `reminder.log` (время и тип: напоминание/завершение).
- Корректно обрабатывает остановку через Ctrl+C и записывает это в лог.

## Как запустить (PowerShell, Windows 10)

1. Убедись, что установлен Python: в PowerShell напиши `python --version`. Если нет — установи с python.org.
2. Создай папку, например `C:\water-reminder`.
3. В этой папке создай файл `reminder.py` и вставь в него код (см. ниже).
4. Открой PowerShell в этой папке (можно зажать Shift + ПКМ в окне папки → «Открыть окно PowerShell здесь»).
5. Запусти скрипт командой: `python reminder.py`.
6. Не закрывай окно PowerShell, пока работает напоминалка. Чтобы остановить — нажми `Ctrl+C`.

## Как добавить в автозагрузку (простой способ)

1. Найди папку автозагрузки: нажми `Win + R`, введи `shell:startup`, нажми Enter.
2. В открывшейся папке создай текстовый файл, назови его `start-reminder.bat`.
3. Открой его в Блокноте и вставь:
   ```bat
   @echo off
   cd /d "C:\water-reminder"
   python reminder.py
