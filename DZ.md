Цель: собрать управляемый промпт, получить стабильный ответ модели и превратить его в небольшой полезный артефакт.

Что сделать
Выбери одну бытовую мини-задачу (пример: напоминание пить воду, расчёт скидки, приветственный бот).
Собери промпт по схеме: роль → контекст → задача → формат ответа.
Обязательный формат вывода: валидный JSON
<code class="language-JSON" style="white-space:pre-wrap;word-break:break-all">{ "title": "...", "steps": ["...","..."], "notes": ["...","..."] }
</code>
Запусти промпт в одном инструменте на выбор (Cursor или ChatGPT).
Зафиксируй параметры: модель, temperature (рекомендуем 0.2), системные инструкции (если есть).

Сделай одну осмысленную итерацию качества — улучши промпт: уточни роль или добавь мини-пример (few-shot). Повтори запуск с теми же параметрами.
Сравни два ответа (до и после итерации) коротко:
Соответствие JSON-формату (да/нет),
Полезность шагов (steps),
Лаконичность notes (до 3 тезисов).
Собери маленький артефакт на базе итогового ответа:
либо README.md для пользователя (что делать по шагам),
либо мини-скрипт/макет интерфейса (если готов).
Формат сдачи
Либо ссылка на GitHub-репозиторий, либо скриншоты, либо zip-архив.
